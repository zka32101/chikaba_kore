# 「あんしんみち」統合計画

## 概要

「近場まっぷ（chikaba_kore）」と、別リポジトリで開発中の「あんしんみち（project-039）」を、
将来的に**「地図」を共通基盤とした総合アプリ**へ発展させる構想の整理・ロードマップ。

- **近場まっぷ**: 地元民と訪問者をつなぐ施設発見・クチコミアプリ
- **あんしんみち**: 影・雨よけ・夜の明るさを考慮した安全な経路探索アプリ

両者とも Flutter + Firebase ベースで、位置情報・地図表示・投稿・課金という共通の要素を持つ。

## 検討の経緯

1. 「合体させた方がよいのでは」という提案から検討開始
2. 単純な1アプリへの即時マージは、価値提案の衝突・UX複雑化・ブランディングの逆効果というリスクがあるため非推奨と判断
3. ただし両アプリとも**プレローンチ段階**（ユーザーゼロ）であるため、今のうちに構造を決める方が後からの統合よりコストが低い
4. 「地図プラットフォーム」を軸に、発見レイヤー（近場まっぷ）と安全レイヤー（あんしんみち）を段階的に統合していく方針に合意

## 主な発見

### 1. project-039の設計パターンの方が成熟している

project-039は全サービスを「抽象インターフェース → Firebase実装 → Local(オフライン)実装」の
三層構造で統一しており、`firebaseAvailableProvider` で実装を出し分ける。
chikaba_kore は `main.dart` の try/catch でフォールバックするのみで、パターンが統一されていない。

→ 統合時は project-039 のパターンに寄せる。

### 2. chikaba_kore にモデレーション機構が存在しない（重要）

chikaba_kore の `reviews` コレクションは、認証済みユーザーであれば誰でも制限なく投稿・即時公開できる。
通報・非表示・承認待ちフローが一切ない。

project-039 は以下を実装済み：
- 投稿レート制限（直近10分で5件超は自動承認スキップ）
- NGワードフィルタ（Remote Config同期、区切り文字回避への正規化対応）
- 相互チェック投票（確認3件で自動承認、通報3件で再審査差し戻し）
- 投稿者の信頼度加重（本人確認済み1.5倍 / 匿名0.7倍）

→ これは統合以前に、chikaba_kore 単独でも早期に対応すべきリスク。

## 重複・統合ポイント

| 領域 | 統合方針 |
|---|---|
| 位置情報サービス | ほぼ同一実装。即座に共通パッケージ化可能 |
| 課金基盤 | ✅ 完了。**RevenueCat に統一**（複数アプリのエンタイトルメントを一元管理しやすいため、chikaba_kore 側を移行。Webhook経由でFirestore `isPremium` を更新する方式） |
| 通知 | project-039 のフォアグラウンド専用バナーキュー実装を chikaba_kore にも導入 |
| モデレーション | project-039 の基盤をパッケージ化し、chikaba_kore のレビュー機能にも適用 |
| 認証 | 統合アプリでの認証方式の使い分け設計が必要（施設閲覧は緩く、投稿は本人確認必須、等） |
| Firebaseプロジェクト | 1プロジェクトに統合するか、マルチプロジェクト運用を続けるか要決定 |
| 地図コンポーネント | カメラ制御・マーカー・現在地ボタン等の基本部分を共通化、描画内容（施設 vs 経路）は分離レイヤーに |

## 未決定の論点

1. **ブランド名** — 「近場まっぷ」で統一するか、新ブランドを立てるか
2. **収益化の統一方式** — RevenueCat 移行の実施時期・移行手順
3. **本人確認の適用範囲** — ✅ 方針決定済み。`docs/AUTH_STRATEGY_DESIGN.md` 参照。Google Sign-Inをベースに、コメント機能等の実名性が必要な操作にのみ電話番号認証を追加リンクする方式。実装はコメント機能統合のタイミングまで保留
4. **project-039 の Firebase プロジェクト詳細** — ✅ 調査済み。project-039 は Firebase Console 上でのプロジェクト自体が未作成（CI の `FIREBASE_PROJECT_ID` も未設定）だったため、`chikaba-map`（chikaba_kore が実際に使用しているプロジェクト）へ統合する方針で決定。両リポジトリの `.firebaserc` を `chikaba-map` に設定済み。残作業: Firebase Console で project-039 用の Android/iOS アプリを `chikaba-map` プロジェクトに登録し、`google-services.json`/`GoogleService-Info.plist` を発行（ユーザー側の作業）
5. **既存ユーザーへの影響** — 両アプリともプレローンチのため現状は影響なし。今後ローンチ時期をどう調整するか
