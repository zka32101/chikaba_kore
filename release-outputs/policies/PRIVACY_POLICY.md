## はじめに

近場コレ（以下「本アプリ」）は、ユーザーのプライバシーを尊重し、個人データを適切に保護することをお約束します。本ポリシーは、本アプリがどのようなデータを収集し、どのように利用するかについて説明します。

本アプリを利用することで、本ポリシーの条件に同意したものとみなされます。

## 収集するデータ

### 1. 位置情報データ

**収集方法**: GPS（ユーザーが明示的に許可した場合）

**用途:**
- 現在地周辺の施設検索
- 距離ベースのフィルタリング（デフォルト: 800m圏内）
- ユーザー体験の最適化

**保存場所**:
- ローカルデバイスのみ
- クラウドサーバーには保存しない
- アプリ終了時に自動削除

**ユーザーコントロール**:
- 設定 > プライバシー > 位置情報 から許可/拒否を切り替え可能
- いつでも位置情報アクセスを無効化可能

### 2. アカウント・認証情報

**収集データ:**
- メールアドレス（メール認証の場合）
- ユーザー名 / ニックネーム
- プロフィール画像（オプション）
- 電話番号（オプション）

**保存方法:**
- Firebase Authentication で安全に保存
- エンドツーエンド暗号化で保護

### 3. ユーザー活動データ

**検索・閲覧:**
- 検索したキーワード
- 閲覧した施設
- フィルター設定

**レビュー・投稿:**
- 投稿したレビューのテキスト
- 評価スコア（1-5星）
- アップロード画像（最大3枚）
- 投稿日時

**お気に入り・ブックマーク:**
- 「行きたい」施設リスト
- 「今行く」施設リスト
- 保存したレビュー

### 4. 分析データ（Firebase Analytics）

**自動収集:**
- アプリ起動日時
- セッション継続時間
- 機能利用パターン
- クラッシュレポート
- エラーログ

**例外:**
- 個人を特定できる情報は含まない
- IP アドレスは収集しない
- ユーザーは設定から分析を無効化可能

### 5. デバイス・システム情報

**収集データ:**
- OSバージョン（Android / iOS）
- デバイスモデル
- アプリバージョン
- 言語設定
- タイムゾーン
- ネットワーク接続タイプ

**用途:**
- 互換性確認
- パフォーマンス最適化
- クラッシュデバッグ

### 6. 画像データ

**レビュー投稿画像:**
- 最大3枚までアップロード可能
- Firebase Storage で暗号化保存
- メタデータ（位置情報など）は削除

## データの利用目的

### 必須用途（ユーザーの同意が必須）

1. **サービス提供**
   - 施設検索・表示
   - レビュー機能
   - お気に入り管理
   - ユーザーアカウント管理

2. **セキュリティ**
   - 不正アクセス検知
   - スパム防止
   - アカウント保護

3. **カスタマイズ**
   - パーソナライズされた推奨
   - 保存された検索条件の適用
   - ユーザー体験の向上

### オプション用途（ユーザーの任意の同意で）

4. **分析・改善**
   - 機能利用パターンの分析
   - バグ修正
   - パフォーマンス最適化

5. **マーケティング・通知**
   - プッシュ通知
   - アップデート情報
   - 新機能のお知らせ

**ユーザーは設定でこれらを無効化できます。**

## データの保持期間

| データ種別 | 保持期間 | 削除方法 |
|-----------|--------|--------|
| **GPS位置情報** | セッション中のみ | アプリ終了時に自動削除 |
| **検索履歴** | ユーザー設定で調整可 | 手動削除またはアプリ設定から削除 |
| **レビュー投稿** | アカウント削除まで | ユーザーが手動削除可能 |
| **プロフィール画像** | アカウント削除まで | 手動削除可能 |
| **Firebase分析** | 13ヶ月（自動） | Firebase自動削除 |
| **クラッシュログ** | 30日（自動） | Firebase自動削除 |
| **認証トークン** | 1時間（有効期限） | 自動失効 |

### アカウント削除時のデータ処理

アカウント削除リクエスト時:

1. **即座に削除**（30日以内）
   - ユーザーアカウント
   - プロフィール情報
   - 認証記録

2. **段階的に削除**（90日以内）
   - レビュー投稿
   - 画像データ
   - 活動ログ

3. **永続保持**（法的要件による）
   - 取引記録（必要に応じて）
   - 監査ログ（セキュリティ目的）

## データの共有

### 原則

- **個人情報の売却**: いかなる場合も売却しません
- **第三者への提供**: 原則として行いません
- **広告関連**: ユーザーの個人情報は広告者に提供しません

### 例外（データを共有する場合）

1. **ユーザーの明示的な同意**
   - 例: 他のユーザーとの共有を希望

2. **法的要求**
   - 裁判所の命令
   - 捜査機関からの正式な要求
   - その他法律で要求される場合
   - この場合、ユーザーに通知します（法律で禁止されていない限り）

3. **サービス関連企業**
   - Firebase（Google）
     - 分析・クラッシュレポート
     - ストレージ（暗号化）
   - Google Maps（位置情報サービス）
   - 決済処理企業（プレミアム機能の場合）

**これらのサードパーティは、本アプリの機能提供のためにのみデータを使用します。**

## ユーザーの権利

### 欧州（GDPR適用地域）のユーザー

以下の権利があります:

1. **アクセス権（第15条）**
   - ご自身のデータが何であるかを知る権利
   - 設定 > プライバシー > データエクスポート から確認可能

2. **訂正権（第16条）**
   - 不正確または不完全なデータを修正する権利
   - プロフィール設定から直接編集可能

3. **削除権（第17条）** — 「忘れられる権利」
   - 特定の状況でデータ削除をリクエスト可能
   - privacy@chikaba-kore.app に連絡

4. **処理制限権（第18条）**
   - データ処理を制限するリクエスト
   - サポートチームに相談

5. **データポータビリティ権（第20条）**
   - ご自身のデータを構造化された形式で取得する権利
   - 設定 > プライバシー > ダウンロード から実行可能

6. **異議申し立て権（第21条）**
   - 特定の処理に異議を唱える権利
   - privacy@chikaba-kore.app に連絡

### 日本（個人情報保護方針法適用）のユーザー

1. **開示請求権**
   - ご自身の個人情報の内容確認

2. **利用停止請求権**
   - 不適切な利用の停止要求

3. **削除請求権**
   - 個人情報の削除をリクエスト

4. **苦情申し立て**
   - 個人情報保護委員会に申し立て

### カリフォルニア（CCPA適用）のユーザー

1. **知る権利**
   - 過去12ヶ月間の情報開示

2. **削除権**
   - リクエストによる削除

3. **オプトアウト権**
   - 個人情報の販売・共有をオプトアウト（当アプリでは販売なし）

4. **非差別権**
   - 権利行使による差別的扱いを受けない権利

### 権利行使の方法

```
Email: privacy@chikaba-kore.app
件名: [ユーザー権利] [リクエスト内容]
本文:
- アカウントメールアドレス
- リクエスト内容（アクセス、削除、修正など）
- 該当データがあれば具体的に記載
```

**回答期限**: リクエスト受付後45日以内

## セキュリティ

### データ転送の保護

- **TLS 1.2以上**: すべてのネットワーク通信を暗号化
- **HTTPS**: ウェブ API は全て HTTPS 経由
- **証明書ピニング**: Firebase 通信でサーバー確認

### ローカルストレージの保護

**Android:**
```kotlin
// Android Keystore を使用した暗号化
EncryptedSharedPreferences preferences = 
  EncryptedSharedPreferences.create(
    context,
    "secret_shared_prefs",
    MasterKey.DEFAULT_MASTER_KEY
  );
```

**iOS:**
```swift
// iOS Keychain を使用
let credentials = NSURLCredential(
  user: username,
  password: password,
  persistence: .permanent
)
```

### サーバー側の保護

- **Firebase Firestore**: 保存時自動暗号化
- **Firebase Storage**: Google管理キーで暗号化
- **バックアップ**: 定期的に実施、暗号化状態で保存
- **アクセス制御**: Firebase Security Rules で厳密に制御

### セキュリティインシデント

万が一データ漏洩が発生した場合:

1. **調査**: 直ちに原因究明
2. **通知**: 影響を受けたユーザーに30日以内に通知
3. **対応**: 修復措置を実施
4. **報告**: 監査機関に報告（必要に応じて）

詳細は [セキュリティポリシー](./SECURITY_POLICY.md) を参照してください。

## 国別規制への対応

### 欧州連合（GDPR）

- 個人データに対する厳密な同意取得
- データ処理の記録を管理
- データ保護影響評価（DPIA）を実施
- 個人データ保護責任者（DPO）を配置

### 日本（個人情報保護方針法）

- 個人情報の適切な利用
- 本人の権利保護
- 個人情報保護委員会との協力

### カリフォルニア（CCPA）

- 消費者の選択肢の拡大
- データ販売の制限
- サービス差別の禁止

## ポリシーの変更

### 変更の通知

本ポリシーを変更する場合:

1. **事前通知**（大幅な変更の場合）
   - 30日前にアプリ内で通知
   - Email でも通知

2. **自動同意**
   - 変更から30日以内に新規利用で自動同意
   - 既存ユーザーには同意リセット

3. **拒否の場合**
   - 新ポリシーに同意しない場合、アプリ利用継続不可
